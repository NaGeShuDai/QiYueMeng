# 第七码头 · 本地纪念网站

双击项目根目录“第七码头.lnk”或“打开纪念网页.bat”，启动本地服务并打开浏览器。重复启动复用现有服务。

## 相册与重要日

支持新增、编辑、删除相册，上传照片、选择封面，设置开始及结束日期和日期说明。点击相册中的照片可以查看原图。
重要日支持每年纪念、倒数、已过天数。已设置 2024-07-28 在一起纪念日（当天计为第 1 天）。

## 本地数据与备份

记录位于 data/collection.json；本次复制的 867 张原图在 data/photos，浏览小图在 data/previews。源目录 _res 未修改。
复制整个 data 文件夹即可备份，也可导出/导入包含原图的 ZIP。带文件路径的 JSON 不能单独迁移照片；旧版 Base64 JSON 仍可导入。导入确认后替换相册与重要日，不自动删除旧原图。

原浏览器 IndexedDB 记录可在原浏览器直接打开 index.html 后导出，再从新入口导入。平时请使用快捷方式进入。

当前电脑已安装 Python；转移至其他电脑需要 Python 3.11 或更高版本。本地服务仅监听 127.0.0.1:18777。本次验证覆盖网页与本地保存，未重新打包 Unity 游戏。

## 回忆幻灯片

点击首页绿色“播放我们的回忆”按钮启动全屏覆盖播放。默认每张 1.5 秒，可改为 1 秒或 3 秒；相册开场 2 秒。文字沿用各相册的说明，不生成照片级故事。点击两侧箭头切换照片；底部可暂停、选择相册、开关音乐或进入浏览器全屏。Esc 关闭播放，音乐停止；相册选择期间暂停。跳过空相册，播放结束可重新开始。

背景音乐：music/memories.wav，本地合成的 64 秒循环轻柔器乐，可替换同名 WAV。
