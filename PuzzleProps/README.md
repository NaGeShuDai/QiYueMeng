# 诗集密室：机关模型资源

本包完成八组机关及线索道具的建模。独立于原卧室场景，未接入 Unity 场景、脚本或解谜流程。整体为复古木质外观，搭配少量黄铜、灯泡和纸张。

## 文件

- `Poetry_PuzzleProps.blend`：可编辑模型源文件，木纹图片已打包。
- `Exports/P01_*.fbx` 至 `P09_*.fbx`：九组独立资源，组根节点位于原点。
- `Exports/Items/`：17 件独立可拾取物品，包括四枚汉字木块。
- `Exports/PuzzleProps_All.fbx`：全部模型的展示布局，包含各组展示物品，不是已安装的卧室。
- `Textures/AntiqueWalnut_BaseColor.png`：木纹贴图，FBX 同时内嵌图片。
- `asset_manifest.json`：部件、交互类型、奖励锚点和机关参数。
- `validation_report.json`：FBX 重新导入检查结果。
- `Renders/PropLibrary.png`：模型总览。

## Unity 接入说明

1. 将 `Exports` 和 `Textures` 复制至 Unity 项目的资源目录。无需安装 Blender；汉字已转换为网格，无字体运行依赖。
2. 先使用各组独立 FBX 安装到卧室。总览 FBX 和独立组任选一种，避免叠放重复模型。
3. 模型以米制作，FBX 导出采用 Y 向上、-Z 向前。不同渲染管线下需用项目自己的 Lit 材质接入木纹和颜色；本包未制作 URP/HDRP 专用材质资产。
4. 转轮、指针、盖板、抽屉和翻片均保留独立层级与操作轴心。为对应节点添加碰撞体，再由脚本实现旋转、滑动、拾取和安装。这里没有动画控制器、碰撞体或交互脚本。
5. `asset_manifest.json` 的位置、角度和 `local_axis` 是 Blender 原始局部坐标描述，不能不经转换直接当作 Unity 位移轴。实际 Unity 脚本应依据导入后的节点轴向设置。
6. FBX 节点可能带 Blender 自动添加的 `.001` 后缀；按层级和清单对应，不要依赖完全相同的字符串查找。
7. 奖励锚点为空节点。展示用拾取物品没有预先塞入每个奖励仓；运行时需移动或生成对应物品，并管理显隐。密码盒、最终盒本身可直接使用对应独立组资源作为奖励。
8. 三件探索物品的卧室藏点、诗集正文与最终线索排版仍需在关卡接入时配置。纸卡是建模占位道具。

## 源文件维护

已保存的 blend 是最终模型，应优先在其上继续编辑。根目录生成脚本顺序为 build → refine → finalize → finish_export；部分精修脚本包含累计位移，不能在最终文件上重复执行。渲染和导出可单独重跑。

已完成 FBX 文件级重新导入验证；尚未进行本批资源的 Unity Play 验证。
