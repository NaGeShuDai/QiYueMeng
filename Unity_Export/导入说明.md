# Unity 独立模型

推荐导入 `Poetry_Escape_Room_Complete.fbx`，其中包含房间、森林与窗口占位平面。导入此文件不需要安装 Blender，也不需要 .blend 文件。

可选拆分文件：`Poetry_Escape_Room_Interior.fbx` 和 `Poetry_Forest.fbx`。不要与完整版同时放入场景，以免重复模型。拆分文件保留相同世界坐标；森林位于房间东侧约 80 米处。

## 材质

4K 房间颜色贴图已烘焙，并嵌入 FBX；`Textures/Room_BaseColor.png` 是随附的独立副本。Unity 若未自动关联，可在模型 Materials 页提取贴图与材质，或手动把该 PNG 指定到房间材质的 Base Map / Albedo。URP/HDRP 项目应使用对应 Lit 材质。森林使用独立纯色材质。

本次烘焙为颜色贴图，不含光照、AO 或程序化凹凸。材质保留金属度和粗糙度数值，但 Unity 不同管线可能需要调整 Smoothness。镜面需要在 Unity 配置反射效果。灯光与相机不包含在 FBX 中。

## 窗口与森林

FBX 仅承载模型、UV 和材质，不包含 Blender Ray Portal 效果，也不含 Unity 脚本。`Window_Portal` 是窗口渲染面的独立组。森林材质已经移除 Blender 专用显示条件。

需要在 Unity 配置森林图层、森林相机、RenderTexture 和正确的视差投影，才能重建“仅从窗口可见”的效果。普通导入时森林是可见网格，可在 Scene 视图隐藏该图层；不要禁用整个森林对象后期待相机仍渲染它。

## 网格

房间尺寸约 5×5×3 米；完整墙体和天花板包含在内。家具和谜题道具保留独立对象，倒角和文字已转换为网格。模型尚未配置碰撞体、交互脚本、动画或谜题状态机。

验证方式：导出后重新导入 FBX，检查网格数量、层级和嵌入贴图解码；本目录没有 Unity 工程，本轮未进行 Unity Editor 实际导入验证。
