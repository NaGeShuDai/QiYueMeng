# 七月梦

一间复古木质卧室，一本诗集，八道相互连接的机关。

## 下载游玩

在本仓库 Releases 下载 Windows 压缩包，完整解压后运行 `七月梦.exe`。
请保留旁边的 `七月梦_Data` 文件夹、UnityPlayer.dll 和其他随附文件，不能只复制 EXE。
诗集为仓库内的 `七月梦.pdf`，也随游戏压缩包附送。推荐在另一窗口或设备打开诗集。

## 操作

- 按住鼠标右键或拖动左键：旋转房间。
- 滚轮：放大、缩小；聚焦物品后也可使用。
- 点击物品：聚焦；再次点击机关进入细节视角。
- 在右侧选择物品，再点击场景中的目标使用。
- Esc：返回上一层视角。
- 右上角“重置进度”：清除当前存档，重新开始。
- 窗口模式可使用 Alt+Enter 切换；关闭游戏使用 Alt+F4。

## 源码

Unity 6000.6.6f1，Windows x64。使用 Unity Hub 打开 `Puzzle`，加载
`Assets/PoetryRoom/Scenes/PoetryBedroom.unity`。
菜单 `Tools > Poetry Room > Build Windows Release` 构建 Windows 版本。

项目不依赖本机 Blender 或 Unity MCP；几何与贴图已作为资源包含。
本库只保留当前项目及最终诗集，不包含旧诗集、编辑器缓存、过程截图和本地工具包。
